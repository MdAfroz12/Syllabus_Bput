# BPUT Syllabus Portal

Syllabus lookup portal for BPUT students — built with ASP.NET MVC & SQL Server

## Features
- Cascading dropdown filters (Course → Batch → Branch → Semester) for quick navigation
- Dynamic syllabus data fetched via SQL Server stored procedures
- Session-based state management for smooth multi-step filtering
- Responsive UI built with Bootstrap 5

## Tech Stack
- ASP.NET MVC 5 (.NET Framework 4.7.2)
- C#
- SQL Server (Stored Procedures, ADO.NET)
- Bootstrap 5, jQuery
